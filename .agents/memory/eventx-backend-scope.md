---
name: EventX backend scope
description: The intended sequence for EventX's frontend demo and later server-backed version.
---

EventX's first release is intentionally frontend-only with browser-local demo data. Do not add a database or Spring Boot backend until the user asks for the later Java + MySQL phase.

**Why:** The user wants a runnable college demo first and explicitly deferred backend work.

**How to apply:** Keep the current demo's interactions local to the browser. When the user asks for the backend phase, discuss how their Java + MySQL requirement should fit into the existing Replit app before making backend changes.
